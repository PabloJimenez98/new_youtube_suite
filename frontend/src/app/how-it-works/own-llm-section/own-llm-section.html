Our own language model (M16)

trained from scratch selectable · Qwen stays the default

yts-own-110m-dpo is a small language model we trained ourselves, from random weights, on the RTX 5070. It can replace Qwen3.5-9B in Chapters, Show notes and Relevance (Settings, or the dropdown on each tool). It is about 90 times smaller than Qwen and saw far less text, so it is an experiment: good at chapter titles, not yet at the other two. Every number below is measured.
