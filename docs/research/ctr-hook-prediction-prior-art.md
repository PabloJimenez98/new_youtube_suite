# Prior Art: CTR/Thumbnail Prediction & Hook-Strength Scoring

Research pass for two planned custom models: (1) title/thumbnail CTR predictor, (2) short-clip hook-strength scorer. Purpose: scope-check against existing academic work, datasets, and competitor tools before committing to an architecture. ~20 sources reviewed across three sub-topics; see per-section notes on coverage limits.

Date compiled: 2026-08-13

---

## 1. CTR / Thumbnail-Title Performance Prediction

**Verdict: moderately well-trodden.** This is an active, multi-year research area (ad-CTR prediction, e-commerce visual CTR, YouTube-specific engagement prediction) with several usable public datasets and a fairly settled architectural pattern: extract embeddings per modality (image + text, sometimes audio), fuse, then regress/rank. No paper we found targets "CTR" in the exact sense of a creator publishing a candidate thumbnail+title pair and asking "how many people out of impressions will click" — most academic work targets adjacent proxies (views, engagement class, ad-CTR at large ad-network scale). That gap (impression→click specifically, at single-channel scale) appears to be where custom modeling work is actually needed, not the general multimodal-fusion approach.

### Architectures / feature patterns

| Approach | Papers/products | Notes |
|---|---|---|
| CNN image embeddings → click probability | [Visual Search / CTR at Pinterest](https://arxiv.org/pdf/1505.07647), [Category-Specific CNN for Visual-aware CTR Prediction at JD.com](https://arxiv.org/pdf/2006.10337) | E-commerce, not video-specific, but establishes the "CNN embedding → CTR head" pattern others copy. |
| Title text (Word2Vec/skip-gram + LSTM) + thumbnail (VGG19) fused | [Title Thumbnail View Predictor (Devpost)](https://devpost.com/software/title-thumbnail-view-predictor) | Hobbyist/student project, not peer-reviewed, but structurally close to what's being planned: exactly two-branch title+thumbnail fusion → view/CTR proxy. |
| Multimodal (title + thumbnail + audio + tags + content) → engagement class | [EnTube dataset/model](https://www.sciencedirect.com/science/article/abs/pii/S187595212500014X) ([preprint](https://www.researchgate.net/publication/363807594_EnTube_A_Dataset_for_YouTube_Video_Engagement_Analytics), [GitHub](https://github.com/truongcntn2017/EnTube)) | 23,738 videos, 72 Vietnamese YouTube channels, 4 genres, 12-year span. Predicts a 3-class engagement label ("Engage"/"Neutral"/"Not Engage") via a custom "Q score," not a continuous CTR. Closest single academic analogue to the planned model's channel-curated-dataset approach. |
| Sentiment analysis of titles+thumbnails → view prediction | ["Clicks for money" (ScienceDirect, 2024)](https://www.sciencedirect.com/science/article/abs/pii/S0148296324003539) | Paywalled, abstract-only access; uses sentiment features from both modalities as predictors of views. Confirms sentiment/emotion is a recurring signal, independent of raw visual/text embeddings. |
| Large multimodal models (VideoLLaMA2, Qwen2.5-VL) → engagement regression | ["Engagement Prediction of Short Videos with Large Multimodal Models" (arXiv 2508.02516, Aug 2025)](https://arxiv.org/abs/2508.02516) | Won ICCV VQualA 2025 EVQA-SnapUGC challenge. Notably found audio modality mattered — VideoLLaMA2 (adds audio) beat Qwen2.5-VL (visual+text only). Suggests title/thumbnail-only models may be leaving signal on the table if audio/hook content is available at prediction time, though for a pre-publish thumbnail+title predictor audio isn't available anyway. |
| Frame-level multimodal transformer for live-stream CTR | [ContentCTR (arXiv 2306.14392)](https://arxiv.org/pdf/2306.14392) | Different setting (live-stream), but a modern transformer-fusion reference architecture. |
| Automatic thumbnail *selection* (not CTR regression) from aesthetic/relevance features | ["To Click or Not To Click" (arXiv 1609.01388)](https://arxiv.org/pdf/1609.01388) | Predicts which frame *within a video* a human editor would pick as thumbnail (1,118 Yahoo Screen videos), using visual quality/sharpness/texture features + content-relevance clustering. Adjacent problem (frame selection) rather than CTR prediction, but useful for aesthetic-quality features. |
| Personalized thumbnail generation via highlight retrieval | ["What Would You Click?" (arXiv 2607.12882)](https://arxiv.org/html/2607.12882v1) | Generative/retrieval angle rather than predictive scoring — relevant if the roadmap later includes thumbnail *generation*, less so for pure CTR scoring. |
| Text-only clickbait/title scoring | [Clickbait detection survey (Papers with Code)](https://paperswithcode.com/task/clickbait-detection/codeless), [word-embedding clickbait detection (arXiv 1710.02861)](https://arxiv.org/pdf/1710.02861), [RoBERTa clickbait detection (Nature Sci Reports, 2025)](https://www.nature.com/articles/s41598-025-30229-5) | Clickbait detection ≠ CTR prediction (it's binary classification against a labeled clickbait corpus, optimizing for "does this look manipulative," not "will this get clicked"), but the text-encoder side (TF-IDF/SVM baselines up through fine-tuned RoBERTa, sentence embeddings) is directly reusable for the title branch of a CTR model. |

### Datasets

| Dataset | Size/scope | Useful for CTR modeling? |
|---|---|---|
| [YouNiverse (arXiv 2012.10378)](https://arxiv.org/pdf/2012.10378) | 136K channels, 72.9M videos, May 2005–Oct 2019, weekly subscriber/view time-series, comment-user mapping | Large but **no thumbnails, no CTR/impressions data** confirmed in the abstract — usable for view-count/channel-growth modeling, not CTR per se. Would need to be joined with separately-scraped thumbnail images if used at all. |
| Trending YouTube Video Statistics (Kaggle-style, referenced in search) | ~150K videos, 10 countries, Nov 2017–Jun 2018, includes thumbnail links, titles, views/likes/comments | Has thumbnails+titles+views, but no CTR/impressions (YouTube never publishes impressions publicly) — same fundamental limitation the project's own OAuth-channel data solves for. |
| EnTube | 23,738 videos, 72 channels | Has title/thumbnail/audio/tags but only a coarse 3-class engagement label, not continuous CTR. |
| BBTV dataset | ~6M videos, 25K channels, Apr 2007–May 2015, daily samples | Channel/metadata scale reference; unclear if thumbnails included. |

**Key structural finding, not just a dataset gap:** every public dataset we found has views/likes/comments but **none has true CTR (click-through-on-impression) data**, because YouTube doesn't expose impressions publicly. This is exactly why the project's own plan (YouTube Analytics API via OAuth for the one connected channel, which *does* expose impressions-based CTR) is the only realistic path to true CTR ground truth — the curated-channel-list data pulled via the public Data API will only ever give view/engagement proxies, not real CTR, for those other channels. Worth being explicit in project docs that "CTR predictor" trained mostly on the multi-channel dataset is actually a proxy-engagement predictor, calibrated/anchored by the smaller single-channel true-CTR dataset.

## 2. Hook / Opening-Strength Scoring for Short-Form Video

**Verdict: genuinely sparse in the peer-reviewed literature — flagging explicitly as requested.** We did not find any academic paper that specifically models "will the first 5-15 seconds of a short clip retain viewers" as a supervised ML task with published methodology, architecture, and evaluation. What exists instead:

- **Industry/creator-education content** (not research) asserting the first-3-seconds cliff pattern, retention benchmarks (e.g., "50-60% of drop-off happens in the first 3 seconds," "intro retention should be >70%") — useful as domain framing/heuristic priors, not as model architecture or training methodology. Representative sources: [TrueFuture Media – Science of the Short-Form Hook](https://www.truefuturemedia.com/articles/science-of-short-form-video-hooks), [Artiphik – First 10 Seconds Retention Playbook](https://artiphik.com/blog/the-first-10-seconds-retention-playbook), [OpusClip – Ideal Shorts Length](https://www.opus.pro/blog/ideal-youtube-shorts-length-format-retention). None of these publish a model, dataset, or evaluation — they're blog-level pattern claims from platform analytics, not verifiable methodology.
- **Adjacent academic work exists but doesn't target "hook strength" specifically:**
  - [Video highlight detection (AHA, NeurIPS 2025)](https://arxiv.org/html/2509.16421v2) — predicts segment-level relevance/informativeness online, without looking ahead. Same "predict engagement per short window" shape as a hook scorer, but trained for highlight retrieval (find the best clip within a long video) rather than "will this specific opening retain viewers." Architecturally transferable (autoregressive, per-segment scoring heads) but not the same task or dataset.
  - ["Slapping Cats, Bopping Heads, and Oreo Shakes" (ACM WebSci 2022, arXiv 2111.02452)](https://arxiv.org/pdf/2111.02452) — studies TikTok virality indicators (close-up/medium shot scale, captions, trending hashtags, follower count) via a hand-labeled 400-video dataset and classifiers. Whole-video virality, not opening-seconds-specific, and a small dataset — useful for feature ideas (shot scale, caption presence) rather than a ready architecture.
  - [AMPS — multi-modal attention mechanisms for short-form video popularity (ScienceDirect 2024)](https://www.sciencedirect.com/science/article/abs/pii/S0969698924000742) — paywalled, abstract suggests multi-modal-attention popularity prediction; likely whole-video, not opening-only, based on title framing. Flagged but not independently verified (fetch blocked, 403).
  - [Engagement Prediction of Short Videos with LMMs (arXiv 2508.02516)](https://arxiv.org/abs/2508.02516) — see Section 1; a per-video engagement regressor, doesn't isolate opening seconds specifically, but same general problem shape (multimodal LMM → engagement score) could in principle be re-targeted to opening-clip-only input.
  - Neuroscience-adjacent: attention-allocation research (cited in secondary sources, not independently verified via primary paper) claims viewers commit attention within the first 8-15 seconds of any video (general, not short-form-specific).
- **A genuinely interesting adjacent research direction, flagged for awareness rather than near-term adoption:** [Meta's TRIBE / TRIBE v2 (arXiv 2507.22229)](https://arxiv.org/abs/2507.22229) is a trimodal (video+audio+text) brain-encoding foundation model trained on 1,000+ hours of fMRI data across 720+ subjects, predicting whole-brain response to naturalistic video/audio/text stimuli, and it won the Algonauts 2025 encoding competition. This is not a hook-scorer and wasn't built for retention prediction, but it's the most rigorous "predict human response to video content" model we found in the entire search, and some commercial "hook score" tools (see Section 3, Higgsfield) explicitly market themselves as trained on fMRI/EEG neuromarketing data in the same spirit. Not something to build on directly (huge, unrelated training target), but worth knowing it exists if the hook-scorer roadmap ever explores physiological-response-inspired proxies (e.g. distilling public neural-encoding models' attention signal as a weak-label source) instead of pure heuristics.

### Bottom line for hook-strength scoring
There is no off-the-shelf academic architecture or public dataset for "score the first N seconds of a clip for retention likelihood." The project's planned approach — bootstrap with heuristics (derived from the creator-education pattern claims above: cliff-vs-gradual-decline framing, first-3-second weighting, shot/caption/pacing features) before real training data exists — appears to be the *only* viable path, not an underexplored shortcut; there's no existing model to fine-tune from and no benchmark dataset to validate against. This sub-topic would benefit from a narrower follow-up search (e.g., specifically vertical/short-form retention-curve datasets from platforms like TikTok's research partnerships, or YouTube Shorts-specific retention studies) if the team wants more before committing, but initial signal suggests it would still come up sparse — the sparsity itself looks structural (retention-curve ground truth is proprietary platform data, not published) rather than a search-coverage problem.

## 3. Existing Tools/Products (Competitive Landscape)

### Thumbnail/title CTR & A/B testing

| Tool | Claimed capability | Notes |
|---|---|---|
| [TubeBuddy](https://www.tubebuddy.com/tools/youtube-thumbnail-test) | Live A/B testing (rotates up to 3 thumbnail variants to real traffic, declares winner by actual CTR/watch-time data), plus a pre-publish "AI Thumbnail Analyzer" with eye-tracking heatmaps | Real-traffic A/B testing (not prediction) is their differentiator — this is ground-truth testing, not a predictive model, and is the most credible category of the bunch since it uses real impressions. |
| [VidIQ](https://vidiq.com/) | Pre-publish thumbnail "CTR prediction" from AI analysis; explicitly does **not** offer live A/B testing | Prediction-only, unverified methodology; positioned as the "predict before you post" complement to TubeBuddy's "test after you post." |
| Thumblytics, PIXADO (ThumbScore), CheckMyThumbnail, Memories.ai, TubeAnalytics, Miraflow | Various "predict CTR/click-probability from visual signals before publishing," claims like "85% accuracy," "50+ visual signals," "6.8% CTR / 3.2x median" | All marketing-site claims with **no published methodology, dataset, or independent validation** found. Treat as directional competitive awareness only — these numbers are unverifiable vendor claims, not benchmarked results. |

### Hook/virality scoring for short clips

| Tool | Claimed capability | Notes |
|---|---|---|
| [OpusClip](https://www.opus.pro/) | "Virality Score" (0-99) explicitly scoring hook quality, payoff, etc., as part of its AI clipping pipeline | Market leader (10M+ users per their own claims). Publicly acknowledged by users/reviewers as inconsistent ("clips rated 40 sometimes outperform clips rated 85") — useful as a cautionary data point that even a well-resourced incumbent's hook-scoring is noisy/unreliable in practice. |
| [Klap](https://klap.app/) | Claims training "on viral short-form video data" to pick hooks/payoffs/emotional peaks | Similar positioning to OpusClip; no published methodology. |
| [Higgsfield Virality Predictor](https://pasqualepillitteri.it/en/news/2273/higgsfield-virality-predictor-hook-score-hold-rate-2026) | "Hook score," "hold rate," and a "brain heatmap," explicitly marketed as trained on fMRI/EEG neuromarketing data | Notable for the neuromarketing framing (echoes the TRIBE angle above) but not peer-reviewed and training data not public — same unverifiable-claims caveat applies. |
| Vidyo.ai, Choppity, and other AI clip tools | General-purpose repurposing with some scoring/ranking features | Positioned more on editing/workflow than on a rigorous predictive score; less relevant as direct competitors to a dedicated hook-scorer. |

**Competitive takeaway:** The market already has several products claiming pre-publish CTR/hook prediction, but none publish methodology, training data, or independently verified accuracy — the bar for a credible, evaluable custom model here is low to clear on rigor even if hard to clear on raw predictive accuracy (nobody has real ground truth impressions data except platforms and connected-channel owners, which is exactly the project's OAuth-data advantage for the CTR model). For the hook-scorer specifically, competitors' scores are widely reported (by their own users) as unreliable, reinforcing that this is an open problem industry-wide, not just internally — the heuristic-first, upgrade-later roadmap looks reasonable relative to what incumbents have actually shipped.

## Flags for Scope Reconsideration

1. **True CTR ground truth is structurally scarce.** No public dataset — academic or product — has impression-level CTR. Every public dataset is views/engagement, a proxy. This means the multi-channel curated dataset (Data API) can only ever train a *view/engagement* predictor unless it's calibrated against the single OAuth-connected channel's true Analytics CTR data. Worth deciding explicitly whether "CTR predictor" is honestly a proxy-engagement predictor with a CTR-calibration layer, since that changes evaluation design.
2. **Hook-strength scoring has no benchmark to inherit from.** This isn't a search-coverage gap — retention-curve data is proprietary to platforms, so there's no academic dataset or pretrained model to fine-tune. Any published "hook score" tool (OpusClip, Klap, Higgsfield) is a black box with self-reported and disputed accuracy. The project's heuristics-first plan is essentially the only viable bootstrap path; framing internal expectations around "we're building the first real version of this" rather than "we're implementing a known technique" seems warranted.
3. **Genuinely surprising/non-obvious finding: neural-encoding foundation models (Meta's TRIBE v2) and their commercial neuromarketing-flavored derivatives (Higgsfield) exist and are being marketed directly at the "hook score" use case.** This is a different technical family (predict physiological/attentional response) from the two natural default choices (heuristics, or a trained-from-scratch classifier on engagement labels) and isn't something the two of us would likely have surfaced without the search. Not recommending adoption now — it's heavyweight, unrelated-domain infrastructure — but worth a conscious "we're aware of this and chose not to pursue it (yet)" note rather than an accidental gap.
4. **Audio mattered more than expected for engagement prediction** in the one directly relevant recent paper (arXiv 2508.02516) — VideoLLaMA2 (video+audio+text) beat Qwen2.5-VL (video+text only). For the hook-scorer (which does have audio available, unlike the pre-publish thumbnail/title CTR case) this suggests audio features shouldn't be an afterthought even in a "just heuristics" first pass.
